## 4. 実行時間の算出方法

- VS Code Chat: 各リクエストの `timestamp`（Prompt入力）→ `modelState.completedAt`（完了）。なければ `elapsedMs` を使用。
- Agent Host/CLI: `user.message`（ユーザー直接入力のみ。スキル注入・システム・サブエージェント・自動継続は除外）→ 次のユーザー入力までの最後の `assistant`/`tool`/`subagent`/`task_complete` イベント時刻。
- 日数は JST の暦日。Promptが1回でもあれば1日。
