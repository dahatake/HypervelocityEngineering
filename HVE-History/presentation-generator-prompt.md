## 4. 厳守する制約

- **金額を載せない**。AI の使用量は「AI クレジット（AIU）の数」だけで書く。USD・円・ドルの記載は不可（モデルが変わると変わるため）。

  - 「254 回 → 5 回」は条件の異なる参考値（n=1。② は前版の要求・コードの 92% を引き継いだ）。
  - BAS の「1 件 3〜6 分」は**目標であり未実測**。BAS の画面は**デモ（お手本パック）**。BAS の要求 144／受入基準 236／System Test 141 は規模の記録で、効果は未取得。
  - Work IQ の 35 問は、情報がテナントに存在しない可能性もあり、方式だけが原因とは断定しない。
  - 「HVE v2 ＝ EABK」は、このストーリーでの置き方。
  - 足場メーター・時間と力のグラフは**概念図（実測ではない）**。
  - 限界: n=1、EABK は自作、試行 1〜6 回、記録は下限値、モデル進化と足場の効果は分離できない。
- 「HVE は失敗だった」と言わない。主旋律は「**当時の合理的な判断を、測って外した**」。判定は誇張せず、解けていない目標（Q7）は正直に NOT YET と示す。
- 顧客名・社内情報・認証情報・API キーを HTML に埋め込まない。
- 点滅・大音量・揺れがあるため、スタート画面で注意書きを出し、`prefers-reduced-motion` では演出を弱める。
- 文体: 日本語、です・ます調。ナレーションは読み上げやすいよう、読点で区切り、数字は読み方を意識する（例: 「66パーセント」「1,096件」）。

## 7. LESSON（学び）の一覧

各クエストや節の終わりに、緑の「LESSON n」バナーを同じ見た目で出す（SE: pinpon）。

1. 補助輪は、当時は正しかった。足りなかったのは**外す基準**（測る仕組み）。
2. 無駄は、**見えて初めて**無駄になる。測る仕組みは、最初に入れる。
3. 足場は 2 種類。「能力不足を補うもの」は外し、「能力に依存しないもの」は**残す**。
4. 規則は、お願いではなく **hook で強制**する。設定だけでは守られない。
5. 補助輪はゼロにせず、**薄く、外から効く場所**だけ残す。そして使い分ける。
6. 再利用できるものは、**データ**に分ける。価値の中心は顧客パック・出典・確度。

## 8. ナレーションとキャラクター

- **ナレーション原稿**を、各シーンのビート（`S.N(text)`）として書く。1 ビートは 1〜2 文。映像は**読み上げが終わるまで次へ進まない**（待ち合わせ）。字幕を画面下に常時表示する。
- **キャラクター**: ユーザーの写真（`media/host.jpg`）を、円形のコミック風アイコン（ハーフトーン・太い縁・名札「HVE 開発者」）にして、**要所だけ**吹き出しで話させる（導入、問いかけ、持ち帰り、締め）。話している間はアイコンを小刻みに揺らす。絵文字のリアクション（👋💡🚀）を添える。
- **音声エンジン**（スタート画面で選択。既定はブラウザー内蔵）:
  1. ブラウザー内蔵（Web Speech API）。日本語音声のうち `Natural`／`Online` を優先。女声をナレーション、男声を開発者に割り当て（男声が無ければ同じ声でピッチを変える）。
  2. **Azure AI Speech の HD 音声**: `ja-JP-Nanami:DragonHDLatestNeural`（ナレーション）／`ja-JP-Masaru:DragonHDLatestNeural`（開発者）。`https://{region}.tts.speech.microsoft.com/cognitiveservices/v1` に SSML を POST（`Ocp-Apim-Subscription-Key`）。
  3. **gpt-4o-mini-tts**: Azure OpenAI（`{resource}/openai/deployments/{name}/audio/speech?api-version=2025-03-01-preview`、ヘッダー `api-key`）または OpenAI 互換。`voice` と `instructions` で、ナレーションは落ち着いて少し速め、開発者は親しみやすく熱量高めに。
  - **API キーはページのメモリにだけ保持し、保存・埋め込みしない**。クラウド呼び出しが失敗したら、自動でブラウザー内蔵に切り替える。最新の提供状況（モデル名・リージョン）は実行時に Microsoft Learn で確認し、使えない場合は入力欄で変えられるようにする。
- 読み上げ中は BGM の音量を自動で下げる（ダッキング）。一時停止・シーン移動・ナレーション ON/OFF（キー N）に音声も連動する。

## 9. 演出・SE・BGM（すべて Web Audio で合成。外部音源なし）

- **テロップ**: 太い縁取りのフチ文字。帯（黄／赤／水色）、スラム（巨大な数字・語が拡大して着地、画面揺れ・フラッシュ・集中線・粒子）、強調色（`{y|…}` 黄／`{r|…}` 赤／`{c|…}` 水色／`{g|…}` 緑）。
- **カメラ**: CSS 3D（`perspective`＋`translate3d`）で、ドリー、オービット、ドリーズーム、円環の中心から見回す（視点を軸にした回転）、手持ち風の揺れ。
- **画面効果**: グリッチ（RGB ずれ）、シネマスコープの黒帯、赤いビネット、フィルムグレイン、星空とパースペクティブ・グリッドの背景。
- **ゲーム／TV 演出**: クエスト導入バナー、CHALLENGE カード、判定スタンプ（CLEAR はファンファーレ）、「CONTINUE? 10→0」、自作ゲートが標準機能に置き換わる UNLOCKED、「再開してください」が流れるコメント、スターウォーズ風クロール。
- **SE（合成）**: whoosh／boom／hit／tick／pop／ding／pinpon／buzz／scratch／riser／glitch／siren／stamp／heart／spark／fanfare／drum／beep／shrink／coin。
- **BGM（合成・ループ）**: drone／tension／drive／epic／calm／outro の 6 ムード。場面の感情に合わせて切り替える。

## 10. 操作・UI

- スタート画面: タイトル、音声ナレーション ON/OFF、クラウド音声の設定（折りたたみ）、**「フル版（約16分）」「SHORT 版（約5分）」の 2 ボタン**、注意書き（点滅・大音量・揺れ。Microsoft Edge 推奨）。ユーザー操作で AudioContext と全画面を開始する。
- 操作バー（画面下にマウスを寄せると表示）: ⏮ ⏸/▶ ⏭、シーン別の進捗バー（クリックでジャンプ）、🗣 ナレーション、🔊 BGM/SE、⛶ 全画面。
- キー: Space＝一時停止、←→＝シーン移動、N＝ナレーション、M＝BGM/SE、F＝全画面、R＝最初から。
- 1920×1080 の仮想キャンバスを、ウィンドウに合わせて拡縮（レターボックス）。タブが非表示になったら一時停止。

## 11. SHORT 版（約 5 分）

同じ HTML の中に、重要点だけを要約した別の再生列を持つ。**ナレーション・キャラクター・SE・BGM は共通**。アーキテクチャ図と航海図の降下は省く。

`open`（冒頭）→ `s_goal`（目的と 7 つの目標、問い）→ `s_era`（足場の時代：×11、27.7万行）→ `s_quests`（7 つの結果を 1 枚の表で。各行に判定スタンプ）→ `s_eos`（7＋3、EOS）→ `s_shrink`（当時の足場 → 今の答え、概念図）→ `s_v2`（4 つの規則、254→5、98%、48% vs 51%、使い分け）→ `s_bas`（60 分以上の失敗、A/B/C、実録画）→ `s_take`（持ち帰り 5 つ、締め）。合計の目安は 4.8 分。

## 12. 実装の指針（品質を担保する設計）

- **ナレーション主導のタイムライン**: 各シーンは `S` オブジェクトに、`S.N(text)`（ビート）、`S.at(t,fn)`、`S.tween(t,dur,fn,ease)`、`S.mv(el,t,dur,{x,y,z,o,s…},ease)`、`S.say`／`S.slam`／`S.lesson`／`S.wl`（成否カード）／`S.verdict`（判定スタンプ）／`S.chal`／`S.arch`（アーキテクチャ図）／`S.media`／`S.play`／`S.flood`／`S.hbar`（横棒）／`S.meter` などを登録して作る。シーンの長さは、ビートの積算から自動で決める。
- **グラフの凡例・ラベルを隠さない**（重要）: 横棒は 3D の箱ではなく**平らな棒**にし、ラベルと数値は棒の手前（`z` を前へ）に置く。縦棒（3D の箱）のラベルも手前へ出す。スタンプや字幕が数値に重ならない位置にする。
- 3D の箱の面は `.sub` ラッパーで包み、`preserve-3d` の入れ子が崩れないようにする。
- スタート画面は実際にクリックされてから音声を初期化する（自動再生ポリシー対策）。
- 音声（ナレーション）の再生が止まって映像が進まなくなる事態を避けるため、**上限時間（安全タイマー）**を持つ。
- 動画（`.webm`）は、シーンに入ったときに該当の位置（オフセット）から再生し、終わったら頭に戻して繰り返す。一時停止に連動する。

## 13. 検証（完了の条件。結果を必ず自分で確認すること）

1. **構文**: `<script>` の中身を一時ファイルへ出し、`node --check`。（PowerShell で JS を書き換えるときは `$('#id')` の `$` が展開されるので、シングルクォートで書く。）
2. **通し実行**: ヘッドレスの Chromium（Playwright）で、全シーンの `goto(i)` と `stepEngine()` を時間いっぱい進め、**`pageerror` と `console.error` が 0 件**であること。フル版は全 27 シーン、SHORT 版は全 9 シーン（`SHORTSCENES`）。
3. **画面の目視**: シーンごとに `?s=&t=&pause=1` でスクリーンショットを撮り、コンタクトシートにして確認する。特に、(a) 横棒・縦棒グラフの凡例とラベルが隠れていない、(b) 3 つのアーキテクチャ図に文字の欠けや重なりがない、(c) 航海図から降下してトピックが現れる、(d) 判定スタンプと LESSON バナーが読める、(e) 動画（EABK Studio／BAS）が再生される。
