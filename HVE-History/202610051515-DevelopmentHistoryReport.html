4. 実行時間の算出方法

  • VS Code Chat: 各リクエストの timestamp（Prompt入力）→ modelState.completedAt（完了）。なければ elapsedMs を使用。
  • Agent Host/CLI: user.message（ユーザー直接入力のみ。スキル注入・システム・サブエージェント・自動継続は除外）→ 次のユーザー入力までの最後の assistant/tool/subagent/task_complete イベント時刻。
  • 日数は JST の暦日。Promptが1回でもあれば1日。

6. データ上の制約・注意

  • 記録が残っているのは VS Code Chat（2026-08-31〜09-15）と Agent Host セッション（2026-09-23〜）です。2026-09-08〜09-23 の間（09-15 を除く）はPrompt記録が見つからず、09-16〜09-18 にコミットがあるものの未集計です。実際の入力日数・回数・時間はこれより多い可能性があります。
  • 保存されているのは /work 等ローカルのセッション履歴のみです。GitHub 上のクラウドエージェント等のログは含みません（github/autopilot の4セッションはイベント未保存のため除外）。
  • ジョブ実行時間は、次のPrompt入力までの間にユーザー確認待ち等が含まれる場合があります。最長の数時間級ジョブは長時間の自律（autopilot）実行です。
