# RPG 風マップの独自性の一覧（FR-1054 AC-293）

RPG 風の表示モード（`EABK-Studio/web/js/maprpg.js`、`rpgaudio.js`、`rpgworld.js`）が、既存の著作物（ドラゴンクエストをはじめとする既存のゲームの楽曲・キャラクター・固有名・画像）を複製していないことを確かめる一覧です。確かめる手順は `docs/manual-tests.md` の「FR-1054 AC-293」です。

## 生成の方法

| 対象 | 生成の方法 | 外部の資産 |
|---|---|---|
| 旋律（野外・街・城） | `rpgaudio.js` の `SCENES` に書いた短い数列（半音の高さ）を、Web Audio の発振器で鳴らす。数列はこの画面のために作った。 | なし（音声ファイル・音源・ライブラリを取得も同梱もしない） |
| 効果音（移動・決定・取消・文字送り・メニュー・通れない） | `SOUND_EFFECTS` の音符表を発振器で鳴らす | なし |
| キャラクター（旅人・住人・案内役） | `maprpg.js` の `drawChar` が、長方形の組み合わせで Canvas に描く | なし（画像ファイルなし） |
| 地形・城・街の建物 | `drawGround`、`drawCastle`、`drawHouse`、`drawDoor`、`drawBridge` が長方形で描く | なし |
| 地名・人物名・用語 | 城と街の名前は利用者の管理データ（目的 ID、エンティティ名から付けた街の名前と「関係なしの街」）、住人の名前はエンティティ名。人物の呼称は「旅人」「住人」「案内役」の一般語 | なし |

## 確認項目（すべて「はい」であること）

1. どの旋律も、既存のゲーム・楽曲の主題や既知の旋律を写していない（耳で聞き、数列を既知の旋律と比べる）。
2. 効果音が、既存のゲームの効果音の再現ではなく、単純な矩形波・三角波・正弦波の短い音である。
3. キャラクターの図柄が、既存のキャラクターの外見（髪型・衣装・配色の組み合わせ）を写していない。
4. 画面に出る固有名（地名・人物名・呪文名・職業名）に、既存のゲームのものがない（「勇者」など特定のゲームの呼称も使わない）。
5. 画像・音声・フォント・ライブラリのファイルを、同梱も取得もしていない（ブラウザーの開発者ツールのネットワーク欄に、同じ配信元以外の要求がない）。
