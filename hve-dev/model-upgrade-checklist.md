# 既定モデル更新時のハーネス再評価チェックリスト（FR-MODEL-09）

既定モデル（[requirement-definition.md](requirement-definition.md) FR-MODEL-01）を変えるときに、どのハーネス部品を外して比べるかの一覧。ハーネスの各部品は「モデルが単独では確実にできないこと」の仮定を表すため、モデルが変わったら仮定を 1 つずつ確かめる。本書は手順の一覧であり、自動の比較実行や設定項目は持たない。

## 使い方

1. 下表の各部品について「今回比べるか」を決める。比べない場合は理由を書く。
2. 比べる部品は、同じ Workflow・同じ入力で「部品あり / なし」を各 1 回実行し、`tokens` / `elapsed` / 成果物の合否を記録する。取得できない指標は `NOT_MEASURED` と理由を書く。
3. 結果を変更記録（PR 本文または `work/` の実行記録）に残す。結果が出るまで部品を外さない。

## 対象部品

| 部品 | 有効化する設定・場所 | 外したときに確かめること |
|---|---|---|
| 事前 QA | `auto_qa`（`hve/runner.py` Phase 0） | 質問票なしで要件の取り違えが増えないか |
| Phase 3 敵対的レビュー | `auto_contents_review`（`hve/runner.py` Phase 3） | 評価なしで要件適合・E2E の FAIL が増えないか |
| 言語指示 | `.github/prompts/runtime/orchestrator/language-directive-ja.prompt.md` | 指示を出力言語だけに絞っても日本語出力が維持されるか |
| 大型 Prompt の固定手順 | `.github/prompts/*.prompt.md` の手順節 | 手順を減らしても成果物の章立てと必須項目が揃うか |
| 計画の分割閾値 | `.github/skills/task-dag-planning/references/planning.md`（参照 9 件 / 500 行） | 閾値を緩めても 1 タスクの失敗率・再試行回数が増えないか |
