# 4. うまく動かないとき・用語集

## うまく動かないとき

| 症状 | 対処 |
|---|---|
| ブラウザーが開かない | ターミナルに出る URL（`http://127.0.0.1:…`）を、手でブラウザーに貼ります。 |
| `python` が見つからない | Python 3.9 以上を入れるか、`py EABK-Studio/studio.py` を試します。 |
| 「EABK のデータ層が見つかりません」 | 起動時に案内を出して終了した場合、対象のフォルダーに `docs/requirements-definition.md`・`docs/catalog.md`・`tests/system/ledger.json` のどれもありません。`--repo` で正しいフォルダーを指定します。EABK を入れただけで要求が未作成のときは、先に `/build` で要求を作ります。 |
| どのファイルが読めているか分からない | `python EABK-Studio/studio.py --repo <リポジトリ> --check` を実行します。見つかった／ない管理データのファイル、解析できた要求・受入基準・カタログ行・台帳のケース・実行履歴の件数、警告を表示して終了します（起動はしません）。データ層があれば終了コード 0、なければ 1 です。ファイルの場所を変えているときは `scripts/ebak.config.json` の `management_files` を確認します。 |
| 画面に出ない（件数が 0） | `--check` の件数が 0 のときは、表の見出しの列名が [08-data-reference.md](08-data-reference.md) の書式と合っていません（例: 機能の表に `要求ID`・`実装ファイル` の列がない）。EABK 本体の[管理データの書式](../../users-guide/03-requirements-format.md)に合わせます。 |
| 整合性保守で `preview-conflict` | Studio の起動後に、別の手段でカタログが更新されています。Studio を起動し直して、もう一度プレビューします。 |
| `?select=` のリンクでメニューが出ない | `select` を付けたリンクは撮影用の表示です。普段は `#/map2d?q=<要求ID>` のように `q` を使います。 |
| 画面が古い | 数秒で自動更新されます。直らなければブラウザーを再読み込みします。 |
| 3D が表示されない／重い | ブラウザーのハードウェアアクセラレーションを有効にします。重いときは「レイヤー」で表示を減らします。 |
| API・テーブルが空 | カタログの「API・イベント」「テーブル」の表に登録がありません（異常ではありません）。 |
| 「実装」が実際と違う | 「実装」はカタログの記載です。カタログの更新は EABK のエージェントへ依頼します。 |
| 要求が一部しか出ない | 要求は `#### FR-001 題名` の見出し形式で書かれたものを読みます。書式は EABK 本体の users-guide「管理データの書式」を参照してください。 |
| ポートが使用中 | 次の番号が自動で選ばれます。`--port 9000` のように指定もできます。 |

## 用語集

| 用語 | 意味 |
|---|---|
| データ層 | EABK が管理する記録（要求定義書・カタログ・System Test の台帳・ID 台帳・実行履歴） |
| 目的（G-001） | 事業としてやりたいこと。要求はどれかの目的に属します |
| 要求（FR / NFR） | FR は機能、NFR は性能・安全などの非機能の要求 |
| 受入基準（AC） | 要求が満たされたと言える条件。検証レベルは system / integration / unit / manual |
| 決定状態 | 承認済み・AI提案（承認待ち）・保留・却下・廃止 |
| 優先度 | MUST（必須）・SHOULD（望ましい）・MAY（任意） |
| BLOCKED | 未回答の質問などで、進められない受入基準 |
| 質問票（Q-） | 決める必要のある事項と選択肢・推奨 |
| PARAM | 閾値・期間などの値の定義 |
| エンティティ | 要求が扱う「もの」（申請・注文など）。データの単位です |
| 共通部品 | 複数の機能が使う部品 |
| コンポーネント | アプリの大きな構成単位（ソースの最上位のフォルダー） |
| カタログ | 機能・API・テーブル・共通部品と、実装ファイル・テストの対応表 |
| System Test の台帳 | 受入基準に対応する試験ケースと、その結果 |
