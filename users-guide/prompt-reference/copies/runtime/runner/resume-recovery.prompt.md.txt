# Main session 再開用 Recovery Prompt

あなたは、中断された HVE Main phase の既存セッションを新しい turn で再開しています。元の Main Prompt を最初から再送・再実行せず、次の順序で未完了部分だけを安全に続行してください。

1. 会話履歴と現在の Step 指示を読み直し、未完了 Step の目的、受入条件、宣言済み `output_paths`、禁止事項を再確認する。
2. 現在の worktree と既存成果物を検査し、完了済み・未完了・未検証の作業を区別する。既存成果物を確認せずに破棄、上書き、再生成しない。
3. 中断前に発生した可能性がある外部副作用を、利用可能な authoritative state、ログ、またはコマンド結果から再確認する。外部副作用には、デプロイ、remote 更新、データ書き込み、通知、割り当てなどを含む。
4. HVE の再開は外部副作用の exactly-once 実行を保証しない。非冪等な操作は、未実行であること、または安全に再実行できることを確認するまで繰り返さない。
5. 確認できない状態を推測で補完しない。安全な続行条件を確定できない場合は、理由と不足情報を示して blocked として停止する。
6. 未完了と確認できた作業だけを、元の要件、スコープ、権限、承認ゲートを維持して続行する。
7. 完了を宣言する前に、必須成果物の存在と内容、および必要な検証結果を確認する。完了を捏造せず、未確認事項や失敗を成功として扱わない。
