# 申請の下書き保存と再開

## 目的

利用者が長い申請フォームを途中で止めても、あとで続きから入力できるようにしたい。
古い下書きが残り続けないように、保持期間を設ける。

## 要求

- 利用者ごと・フォームごとに、入力途中の内容を保存できる。
- 保存した内容を、あとで取り出して再開できる。
- 保持期間を過ぎた下書きは、再開できない。
- 利用者の下書きの一覧を取得できる。
- 提出すると、下書きは消える。
- 期限切れの下書きをまとめて削除できる。
- 内容は JSON ファイルに保存する。

## 決まっていない点と、聞かなかった場合の既定

次の点は、依頼に書かれていない。作業の中で依頼主に確認してよい。
確認しなかった場合は、右の既定を適用する。

| 論点 | 既定 |
|---|---|
| 保持期間 | 30 日。保存した時刻から数える。ちょうど 30 日経った時点で期限切れ。 |
| 保存のたびの期限 | 上書き保存すると、期限は保存時刻から数え直す。再開しても延長しない。 |
| 同じ利用者・同じフォームの下書き | 1 つだけ。上書きする。 |
| 内容の大きさ | JSON にした内容が 65536 バイトを超えたら拒否する。 |
| 期限切れの下書きの扱い | 再開しようとしたら、存在しないのと同じ扱い（`DraftNotFoundError`）。 |

## 公開インターフェース（固定）

Python 3.11、pytest。第三者のランタイム依存は使わない。パッケージ名は `drafts`。リポジトリ直下に置く。

### 例外（`drafts` から import できる）

- `DraftError(Exception)`：基底。
- `DraftNotFoundError(DraftError)`：下書きがない、または期限切れ。
- `DraftTooLargeError(DraftError)`：内容が大きすぎる。

### クラス `drafts.DraftStore`

| 呼び出し | 動作 |
|---|---|
| `DraftStore(path, retention_days=30, clock=None)` | `path` は JSON ファイル（なければ作る）。`clock` は引数なしで `datetime.datetime`（タイムゾーンなし）を返す関数。`None` なら現在時刻。 |
| `save(user, form_id, data)` | `data`（JSON にできる `dict`）を保存し、期限を数え直す。 |
| `resume(user, form_id) -> dict` | 保存した内容を返す。ない・期限切れなら `DraftNotFoundError`。 |
| `list_drafts(user) -> list[str]` | 期限切れでない `form_id` を昇順で返す。 |
| `submit(user, form_id) -> dict` | 内容を返し、下書きを消す。ない・期限切れなら `DraftNotFoundError`。 |
| `purge_expired() -> int` | 期限切れを削除し、削除した件数を返す。 |

保存は呼び出しのたびに `path` へ書き込む。同じ `path` で `DraftStore` を作り直すと、内容が残っている。
